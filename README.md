# GridGame2026

## Project summary

### This is a recreation of GridGame2017 that was created within a labview enviroment and is now a web application.

GridGame2026 is a web application that allows players to maintain a simulation of a microgrid that balances out generation load with generation gain where they have to keep the frequency of the energy they provide between 58 Hz and 62 Hz.
